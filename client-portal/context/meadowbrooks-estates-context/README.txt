Important
---------

Some external resources use CORS protection or authentication.

When an asset cannot be downloaded, its original URL and contextual
information are still retained in page-context.json and assets.json.

Image context is inferred using:

1. Captions
2. Alt/title metadata
3. Shared content containers
4. Heading proximity
5. On-screen spatial proximity
6. Shared page sections

Each image therefore includes a contextConfidence value and ranked
contextCandidates instead of pretending every association is certain.
