How It Works / Detailed Installation

A finished result starts with a better route.

A multifamily repipe is a building project, a resident project, and a plumbing project at the same time. The installation sequence is designed to keep those pieces coordinated.

The project process

Five phases through an occupied building.

Every building has its own constraints. These five phases show how the work moves from assessment to a finished, accessible system.

The goal is a well-coordinated project with as little unnecessary opening and restoration as the building allows.

01

Assessment & proposal

Understand the building, existing pipe, constraints, occupancy, and the route that will support the replacement system.

02

Prepare the building & residents

Coordinate access, communication, protection, staging, and the practical details required to work in occupied homes.

03

Install around occupied homes

Install the replacement system through the planned route while keeping the work focused on the spaces that actually require access.

04

A finished result, not a construction zone

Complete the architectural treatment and leave each work area as a finished part of the building.

05

Built for future access

Close the project with a known enclosed route that remains serviceable when the plumbing needs attention later.

Why install it this way?

See the accessible plumbing idea behind the sequence.

The installation method and the finished system are connected. Routing, enclosure, and future access are decisions made during the project—not after the walls close.
